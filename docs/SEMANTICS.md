# 数值与边界语义

## 0.2.0 本地新增：硬 DTW、DBA、聚类与预处理

### 硬 DTW 及窗口

`dtw_path` 以加权平方差为局部代价，返回最小路径的代价 `squared_cost`、其平方根 `distance`、零基下标路径和 `visited_cells`。路径包含首尾，只允许向右、向下、斜向移动一步；代价相等时依次优先斜向、向上、向左，不承诺与其他实现的并列路径相同。

`window=-1` 不限制路径（类型接口）；`window=r>=0` 为 Sakoe-Chiba 半径，不等长时沿较长轴延长：以零基 i、j、长度 n、m 表示，n≤m 时允许 `i-r ≤ j ≤ i+(m-n)+r`；n>m 时允许 `j-r ≤ i ≤ j+(n-m)+r`。等长 `r=0` 只允许对角线；不等长 `r=0` **不等于**只允许一条逐点对角线。JSON 中省略 `window` 表示不约束，整数输入不接受 -1。

实现遍历并分配完整 `(n+1)×(m+1)` 矩阵，`visited_cells` 只统计窗口内非填充格点，不能当作实际循环次数、真实内存使用或时间保证。`max_cells` 限制 n×m；工作预算按完整 n×m×维度计费，窗口不减少预算计数。窗口改变的是允许的路径，不宣称本实现采用了带状内存优化。DTW 不满足一般意义上的三角不等式。

### DBA

`dba_fit` 从调用者指定的固定长度 seed 出发：对每个样本求硬 DTW 路径，再按路径将对应点做样本权重平均，更新原型。优化目标是归一化正样本权重的平方 DTW 代价平均值。允许每个样本长度不同，样本最多32条，原型长度不自动推断。特征权重为0的坐标沿用原模板，因为目标对这些坐标无约束。

`max_steps=0..200`、`tolerance=0..1000`，`example_weights` 为空代表等权，否则每项有限且在 (0,1000000]。停止原因：`max_steps`、`improvement_tolerance`、`work_budget`、`numerical_stall`。下降阈值按 `tolerance × max(1,abs(前目标))` 判断；新目标若因数值原因高于旧目标，不接受该步并返回 `numerical_stall`。`history` 包括初始值和所有接受结果；预算不够初始评估时报错，否则停止前返回最后完整评估的模板。实现不保证全局最优。

### DTW / DBA 聚类

`dtw_kmeans` 接受 1..32 条样本和 1..min(16,样本数) 个**调用者提供的初始中心**，中心长度可以不同，迭代中各中心长度保持固定。分配时选择平方 DTW 代价最小的中心，完全相等时选下标较小者；更新时对该簇用 DBA。`inertia` 是全部样本所选平方 DTW 代价的平均数，`history` 包括初始目标和已接受的完整迭代。

`max_iterations=0..50`、`max_dba_steps=1..50`。返回的停止原因有 `max_iterations`、`improvement_tolerance`、`work_budget`、`numerical_stall`。预算不足初始的全部分配返回错误；预算在中途用尽时返回上一组**已完成最近中心分配**的中心及标签，已消耗但丢弃的中间工作仍计入 `work_units`。不保证簇数最优或全局最优。输入、种子、约束或迭代结果导致某簇无样本时返回 `empty_cluster`；调用者需要换中心或减少 k。不会假装自动重新选中心，也没有自动 k-means++。

### 重采样、标准化及组合流程

`resample_linear` 沿等距**样本下标**线性插值到 1..512 点；有界原始输入允许 1..8192 点、1..16 特征。它不理解实际时间戳，也不做抗混叠。只有一个目标点时取首点，只有一个输入点时重复；极端值处仅对浮点末位可能导致的值域越界截回输入规定范围。

`standardize` 对**每条序列、每个特征独立**计算总体均值 / 总体标准差，标准差≤epsilon 的特征输出0并标记为常量；epsilon 不加到分母。完全相同的浮点输入明确视为常量。标准化会消除每条序列的平移和尺度：如果绝对数值对业务重要，应关闭或自行选择合适预处理。

`prepare_series` 的 target_count=0 表示保持长度，其他允许1..512；超过512点的原始输入必须显式指定输出点数。先重采样、再标准化。即使未开启标准化也验证 epsilon，且返回独立数组。`prepare_and_cluster` 将 1..32 条输入逐条处理，以不重复的输入零基下标指定 1..16 个初始中心，然后调用同一 DTW/DBA 聚类。预处理后的序列、均值、标准差和常量标记可复核；关闭标准化时这些统计数组为空。预处理验证所有原始值，成本 O(原始值数量＋样本数×输出长度×特征数)，不纳入聚类的逻辑 DP 工作预算，但仍受输入形状及请求大小上限约束。

## 0.1.x 原有 Soft-DTW 数值语义

## 目标和梯度

局部代价 `c(i,j)=Σ_k w_k (x[i,k]-y[j,k])²`，默认 w=1。使用上 / 左 / 左上三种转移，路径必须经过首尾格点。原始 Soft-DTW 是所有路径代价的平滑最小值，前向对最小前驱平移后计算 log-sum-exp；逆序传播用同一稳定 softmax 的权重，不用含无穷填充项相减的反向公式。

校正目标 `D(x,y)=S(x,y)-S(x,x)/2-S(y,y)/2`。求 x 的梯度包含 S(x,x) 的**两侧**输入导数，y 同理。`alignment[i,j]` 是 cross 项对局部代价的导数，即该格点的路径访问占用。每个值在数值误差内为 0..1，整个行不要求归一；不能把它当作分类概率或硬匹配。

Soft-DTW 原始值可以为负。校正值不做零截断，否则会改变梯度；极端尺度下接近零的值可能有浮点抵消误差。不同 gamma、尺度或特征权重下的分数不可直接跨配置比较。这里提供平方欧氏代价的数值目标，没有把所有参数组合声称为严格度量。非常小的 gamma 接近硬最小，导数会集中在最优路径附近，浮点数也可能无法区分接近的路径。

## 输入范围

- DTW / Soft-DTW / 聚类等数值分析每条序列 1..512 个采样、1..16 个特征；仅预处理入口接受最多8192个原始采样点，并须压缩到不超过512点后才能进入分析。每个值有限且在 ±10000 内。不处理空序列、NaN、无穷或缺失数据。
- gamma 在 (0,10000]。特征权重为每维一个有限数，范围 [0,1000000]，至少一项正；零权重忽略该维。
- max_cells 在 1..262144，限制**每一个** DP 矩阵的非填充格点。校正 / 拟合包含自项矩阵，cross 合法不代表 self 合法。单次原始计算 O(n·m·d) 时间，O(n·m+n·d+m·d) 空间；校正目标还需 n² / m² 自项。
- fit / rank 最多 32 条示例或候选。候选 ID 非空、唯一、至多 80 UTF-16 单元。相同分数按输入次序排列；rank 会评估全部候选，预算不足直接错误，不返回部分排序。
- 原有 Soft-DTW 运算本身没有带宽约束，也不会自动归一化或重采样；调用者可先使用 0.2.0 新增的独立预处理接口，硬 DTW 另支持窗口约束。项目不提供在线流、GPU、大规模索引、分类器、自动确定原型长度或设备连接；调用者仍需选择尺度、目标长度和 gamma。

## 模板拟合

最小化归一化正示例权重的 `Σ a_i D(prototype, example_i)`，原型长度和维度固定。示例权重范围 (0,1000000]。初始化来自调用者 seed，结果依赖初始化；不是自动分群。仅使用带 Armijo 条件的梯度下降，起始步长每次重置，最多 24 次减半。超出值域的试探点被拒绝并缩步，不会隐式裁剪。

固定示例的 S(example_i,example_i) 只计算一次，原型自项每次目标评估计算一次；原型自项两侧梯度都参与优化。接受步满足目标下降判据；不返回未通过判据的试探点。

### 预算和终止

max_steps=0..200、max_evaluations=1..2048、max_work_units=1..100000000。学习率 [1e-8,10]，两种容忍度 [0,1000]。工作量单位定义为**逻辑矩阵格点数 × 特征数**，不等于 CPU 指令、真实时间或内存字节；反向传播和 exp/log 的常数开销未另计。小预算不构成严格实时保证。

设原型长 p、示例长 m_i、维数 d。准备工作 P=`Σ m_i²·d`；一次目标评估 Q=`(p²+Σ p·m_i)·d`。初始评估计1次，总工作量 `P + evaluations·Q`，超预算前停止。若 P+Q 无法容纳则返回 work_budget 错误；已有初始点时预算耗尽返回 `ok` 的最后完整状态。候选因值域被拒绝时未实际计算目标，不占 evaluations / work_units，但占 24 次回溯尝试。

| stop | 含义 |
|---|---|
| gradient_tolerance | 梯度二范数不高于设定值 |
| improvement_tolerance | 接受步的下降不高于 tol × max(1,abs(前目标)) |
| max_steps | 完成用户设定的步数（含0） |
| evaluation_budget | 下一次评估将超过次数预算 |
| work_budget | 下一次评估将超过逻辑工作量预算 |
| line_search_stalled | 24 次回溯内没有接受点 |

所有状态仅描述这一次局部优化，不代表全局最优。`history` 长度为 accepted_steps+1，包含初始目标；gradient_norm 对应最终返回原型。max_steps / line_search_stalled 可能仍有较大梯度，调用者需要检查它。

## 数据与并发

核心不访问文件或网络，不持有后台任务。输入数组只读，输出新分配；调用期间不能由其他线程修改同一个输入数组。Node / 浏览器包装限制请求体大小。浏览器使用 Worker，通过取消直接终止计算，不保存输入到服务器或本地持久存储。
