# 三个已经运行的合成数值场景

本文件说明选题验证实验的输入、运算和实际结果。当前以 MoonBit typed API 和固定示例运行，不是已经完成 JSON 文件 CLI、完整网页或真实设备业务验证。

共同运行方式：在 `D:\CodexProjects\WarpFit` 执行 `moon run cmd/demo --target js`。全部数据与调用在 `cmd/demo/main.mbt`，核心实现在 `core/soft.mbt`。`python verify.py` 留存各条命令的真实结果。

## 1. 从不同节奏的观测拟合参考模板

- 目标用户：传感器应用或重复工艺数据工具开发者。
- 问题：记录长度与节奏不同，直接按下标平均可能错配峰值。
- 输入：一维观测 `[0,1,0]` 与 `[0,0.8,1,0]`，长度为 4 的初值 `[2,-1,2,0]`，gamma=0.4，最多 30 次下降。
- 操作：对每条观测计算自项校正目标及梯度，平均后通过回溯确定可接受更新。
- 实际输出：平均目标从 `6.724196713736497` 下降至 `0.08787917729654145`，接受 30 步，并返回拟合后的 4 点模板。
- 验证：测试核对每个接受步的目标不增加，输入梯度另由独立穷举与有限差分核对。目标降低不证明模板在真实设备上有更高识别率，也不证明全局最优。

## 2. 取得可用于更新时序模型的多变量梯度

- 目标用户：需要数值损失接口的时序模型开发者。
- 输入：预测 `[[0.2,-0.3],[1.5,0.8]]`，目标 `[[0,-0.2],[0.6,0.4],[1.2,0.9]]`，gamma=0.8。
- 操作：调用 `divergence`，取损失及对两侧全部元素的梯度。
- 实际输出：目标 `0.7998364090182977`；预测第一个元素的梯度 `-0.11180129274548832`，完整梯度长度分别与两侧输入一致。
- 验证：MoonBit 测试针对该多变量输入执行中心有限差分；40 组小规模数据另以枚举路径的直接公式核对原始/校正值和两侧梯度。
- 边界：只返回数值梯度，不含自动微分框架、预测网络或训练数据管理系统。

## 3. 比较参考周期与候选片段

- 目标用户：离线周期数据比较工具开发者。
- 输入：参考 `[0,1,0]`；候选为相同序列、节奏/长度不同的 `[0,0.8,1,0]`、变化序列 `[1,0,1]`；统一 gamma=0.4。
- 操作：分别计算自项校正目标；API 另可输出对应格点占用，用于显示对齐关系。
- 实际输出：相同序列 `0`；节奏变化序列 `0.1813520905973129`；变化序列 `1.7031942663182167`。
- 验证：演示包含上述固定样例顺序的真实断言；小规模数值另经独立穷举对照。
- 边界：这个排序只对该输入和参数成立，不是任意数据的分类准确率，不输出未经标定的概率或合格判定。特征选择、量纲和阈值需要具体应用验证。

## 单独的语义检查

同一输入 `[0,1]` 在 gamma=1 时，原始 Soft-DTW 为 `-0.5514447139320511`，自项校正值为 `0`。这是两种目标必须明确区分的原因。对齐占用矩阵也不保证每行和为 1，不能直接冒充归一化注意力矩阵。
